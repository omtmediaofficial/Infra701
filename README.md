# Infrastructure 701 Legal

A responsive, multi-page static website for INFRA701 LEGAL. It uses the supplied neon-sign logo and a custom generated consultation image, optimized for web delivery, with a charcoal, ember, and warm-paper visual system.

## Build

Requires Node.js 18 or newer. From this folder, run:

```powershell
node build.mjs
```

The build creates the HTML pages, `sitemap.xml`, and `robots.txt` directly in this folder. No package installation or build service is required. The site can be hosted from the repository root on any static host.
